# Sales Performance Analysis — Alfido Tech

## Project Overview

This project analyzes sales performance across regions, categories, sub-categories, products, and time periods.

The objective is to identify high- and low-performing areas, understand sales trends and seasonality, and provide actionable tactical recommendations for improving sales performance.

## Key Results

| Total Orders | 4,922 |

| Worst Region | South |
| Best Category | Technology |

| Best Sub-Category | Phones |

| Best Sales Month | November |
